# Contributing

Code coverage is enforced.

For features:

- Please make sure that there are a few tests covering your new feature

For bug fixes:

- Please add a test to reproduce the bug

## Building

```shell script
pnpm run build
```

## Testing

```shell script
pnpm test
```

## Dependencies

- winston-transport
- discord.js

## Development

- pnpm
- ESLint
- Vitest
- Prettier
- TypeScript
